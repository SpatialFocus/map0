OGC API Features

OGC API Features provides vector data as GeoJSON through collection URLs. map0 loads the data in pages, following the next links in each response.

Try it: open the network tab and reload the page. Around 2,600 railway stations in Great Britain load in pages of 1,000. Each response links to the next page. Hover over a station to see its name. The airports fit in a single page.

Configuration

Set url to the collection URL, such as …/collections/railwaystation. map0 appends /items and requests GeoJSON. The layer supports the same style, cluster, popup and hover options as a geojson layer.

When to use OGC API Features

        

          Like WFS, OGC API Features retrieves current data from a
          service each time the map loads. Changes in the source database become available on the
          next reload. Collection URLs and links to subsequent pages make requests straightforward
          to configure. Request times and data volume depend on the service and the selected
          features. For data published as a file, GeoParquet
          can reduce download size. For larger datasets, vector tiles such as PMTiles let the
          browser load only the parts needed for the current view.
