Coordinates

Display coordinates in the systems used by your organisation, including WGS84, Austrian Gauß-Krüger and UTM.

Try it: right-click anywhere (or press and hold on a touch device). Each row has a copy button.

What this demo shows

  • Open the coordinate display with a right-click or long press
  • proj4 transforms the coordinates in the browser
  • Built-in definitions: MGI/Gauss-Krueger M28, M31, M34, Austria Lambert and all UTM zones
  • Any other CRS works by supplying a proj4 def in the config (EPSG:3416 below)

Without a crs list map0 chooses sensibly by itself: WGS 84, the Gauss-Krueger strip matching the clicked longitude, and the matching UTM zone. That default is what the other demos on this site use.

Coordinate display. These settings control the numbers shown when you select a location. They do not change the map projection or reproject raster tiles. For GeoJSON and GeoParquet data in another CRS, use the layer’s crs setting.

Configuration


        
Defaults and disabling the display

        
          "controls": {
            "coordinates": true,   // WGS 84 + matching GK strip + matching UTM zone
            "coordinates": false   // no readout at all
          }
