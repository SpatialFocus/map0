Languages

The viewer includes German and English. Override interface text per language in the config, or add your own translations.

Look closely: the panel is titled Kartenthemen, not the built-in Kartenebenen, and the legend reads Zeichenerklärung. Both come from i18n.overrides. Tooltips of the MapLibre controls follow the same locale.

How the locale is chosen

  • locale: "auto" (the default) follows the visitor's browser language
  • Set locale to fix the interface language
  • fallback catches keys the chosen locale does not define
  • Add translations for another language through config overrides

For each key, map0 checks the locale’s override and built-in dictionary, then the fallback language’s override and dictionary. If no translation is found, it displays the key itself.

A new language from config alone

        
          "i18n": {
            "locale": "it",
            "fallback": "en",
            "overrides": {
              "it": {
                "layers.title": "Livelli",
                "basemaps.title": "Mappa di base",
                "legend.title": "Legenda"
              }
            }
          }
        

        
Anything not translated falls back to English rather than disappearing.
