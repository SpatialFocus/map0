Map features

Layer tree

Fourteen layers of Vienna open data, sorted into groups. A filter box narrows the tree, each group switches as a whole, and a radio group shows one imagery layer at a time.

Try it: type cycl into the filter box, switch "Mobility" on and off with the box in its header, and pick another imagery layer.

Groups

  • Nesting: a group holds layers and other groups; the order in the config is the order on the map, top of the list on top
  • Collapsed: collapsed: true starts a group closed, like "Education" above
  • All on, all off: the box in a group's header switches every layer in it; a dash means some of them are on

Radio groups

exclusive: true turns a group into a radio group: one child is visible at a time. That suits alternatives that would only cover each other, such as imagery from different years or analyses of the same area. A child group counts as one option and switches as a whole.

The first child configured visible starts on, the others start hidden. The rule also holds for api.layers.setVisibility() and for share links. The box in the group's header switches the group off entirely, and on again with the option that was on or the first one.

Filter box

The filter box appears from ten layers on. controls.layerSwitcher.filter shows it always (true) or never (false); the default is "auto".

  • Forgiving: case and accents do not matter, strasse finds "Straße"
  • Groups count: a word that matches a group title keeps all of the group's layers, several words must all match; a group's box then switches only the layers on show
  • Quick to undo: Esc clears the filter, collapsed groups open while it is active
