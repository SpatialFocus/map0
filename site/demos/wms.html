Data sources

WMS

The workhorse of every spatial data infrastructure: a raster map service, queried on click and explained by a legend the server draws for us.

Try it: click the zoning plan to query the service, adjust opacity in the layer panel, then enable the tree cadastre. Trees appear from zoom level 15; the panel shows when a layer is outside its zoom range.

What this demo shows

  • WMS layers requested as tiles in EPSG:3857, the CRS required for raster rendering in map0
  • info turns a layer into a queryable one: clicks become GetFeatureInfo requests
  • legend: "auto" pulls a GetLegendGraphic image into the legend panel
  • minZoom keeps a heavy layer off small scales, and the layer panel explains the gap
  • metadata.url links a layer to its catalogue entry

map0 builds the GetMap URL for you, including the axis-order-safe CRS parameter for WMS 1.3.0, and keeps any vendor parameters your base URL already carries (a MapServer map= path, for example).

Direct browser access. Capabilities, tiles and GetFeatureInfo responses are loaded directly from the service. Its CORS headers must allow access from the page.
