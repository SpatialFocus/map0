Map features

Share & permalink

Share the current map view and layer settings through a link.

Try it: pan the map, toggle a layer or adjust its opacity. The address bar updates automatically. The share button at the top left copies the link; open it in a new tab to restore the view.

What travels in the link

  • View: centre, zoom, and bearing/pitch when they differ from north-up
  • The active basemap
  • Layer visibility and opacity where they differ from the config
  • Layers the user added at runtime, with their full definition

The link stores changes to the configured state. Other settings continue to come from the config, so an updated layer title also appears when an older share link is opened.

Living with the host page

The state is base64url-encoded in a hash parameter, #map0=… by default. Other hash content is preserved. Change the parameter name if it conflicts with your application: 

          "permalink": true,
          "permalink": { "param": "karte" }

Updates are debounced and use history.replaceState, so moving the map does not add browser history entries.
