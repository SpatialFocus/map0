Vector tiles

The format MapLibre was built for. Three overlays are cut from the same basemap.at vector tile service and styled completely differently — client-side, at 60 fps.

Try it: toggle the three overlays, then switch the basemap to None — the vector layers keep rendering, because the drawing order and the sources are re-injected into every style change.

What this demo shows

  • One vector tile service, three overlays — each picks a different sourceLayer
  • style takes real MapLibre style-spec layers; source and source-layer are injected by map0
  • Styling stays data-driven: colours, widths and dash patterns are just paint properties
  • Legends are written by hand here, because a style can say more than a swatch can show

Unlike raster overlays, vector tiles are restyled without a single new network request — switching the basemap or changing opacity is a GPU operation.

Field note: relative TileJSON basemap.at's TileJSON declares its tiles as tile/{z}/{y}/{x}.pbf — relative, which MapLibre does not resolve. map0 fetches the TileJSON, makes the templates absolute and adopts its zoom range, which also prevents 404 storms from overzoomed requests.

PMTiles

        

          A single-file tile archive on plain storage — no tile server. It is the same layer type
          with a pmtiles:// URL; the protocol handler is loaded on demand the first
          time such a layer appears in a config:
        

        
          {
            "id": "zoning",
            "type": "vector",
            "title": "Zoning",
            "url": "pmtiles://https://tiles.example.gv.at/widmung.pmtiles",
            "sourceLayer": "widmung",
            "style": [
              { "type": "fill", "paint": { "fill-color": ["get", "colour"], "fill-opacity": 0.45 } }
            ]
          }
        

        

          The public Protomaps demo bucket does not send CORS headers, so this page cannot show a
          live PMTiles layer — host the file yourself (any static bucket that supports HTTP range
          requests works) and it behaves exactly like the overlays above.
