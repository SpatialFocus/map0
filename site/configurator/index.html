No JSON by hand

Configurator

Build a map without writing JSON: add layers from WMS, WMTS, WFS or OGC API services, arrange them, set up popups, legends and appearance, and watch the map update. The result is the same config the viewer reads — copy it into a CMS field or download it.

How it works

  • The preview on the right is the real <map0-viewer> — what you see is what the config produces.
  • Layers → From a service reads the capabilities of a WMS, WMTS, WFS or OGC API and lets you tick the layers to add; feature info, extents and metadata links come along.
  • JSON & export holds the config, a copy-ready embed snippet and the import: paste JSON, load a file or a URL. ?config=/configs/wms.map0.json and the ?c= links of the demos work here like in the playground.
  • Your work is kept as a draft in this browser until you discard it. Nothing is sent anywhere.

Every key the forms set is documented in the config reference; the playground is the place for hand-editing the JSON with a live validator.
