Playground

Edit the config on the left and apply it to the map on the right. Start with the example or open a demo here. Validation results appear below the editor.

Service access: a valid config can still point to a service that is unavailable or blocks browser access through CORS. The affected layer reports a loading error. Remote HTTP URLs are rejected on HTTPS pages to prevent mixed content.

How configs get here

  • Use “Open in the playground” below a demo map to load its config here
  • ?config=/configs/wms.map0.json loads any config file of this site into the editor.
  • The map reloads when you apply a valid config. While you edit, it keeps the previous state and appears blurred to show that the changes have not been applied.

See Config validation for checks in editors, build pipelines and the viewer.
