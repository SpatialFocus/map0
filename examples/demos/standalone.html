Integration

Script tag embed

This page loads the built bundle instead of the development sources — the same file you would drop next to a CMS page. No bundler, no framework, no build step on your side.

Note: if the map above is missing, run pnpm demo:standalone once — it builds the bundle and copies it next to this page. Every other demo runs from source via the dev server.

The whole integration

          <script type="module" src="/map0/map0.js"></script>

          <map0-viewer
            config-src="/configs/environment-map.json"
            style="height: 520px">
          </map0-viewer>

The bundle comes from npm — npm install map0-viewer — and node_modules/map0-viewer/dist is the folder you copy. The package name is the one npm would give us; the element, the config and this folder are map0.

If you would rather not host anything, replace that first line with a pinned CDN URL — the element below it stays exactly as it is, and there is nothing to copy onto your server. The entry finds its chunks and MapLibre's worker on the CDN just as it does in your own folder: 

          <script type="module"
                  src="https://cdn.jsdelivr.net/npm/map0-viewer@0.0.2/dist/map0.js"
          ></script>

unpkg.com/map0-viewer@0.0.2/dist/map0.js serves the same tarball. Pin the exact version either way: the config schema is still v0.

Self-hosted, this is what ends up on your web server:

  • map0.js — the client, MapLibre and all UI included
  • maplibre-gl-worker.mjs and maplibre-gl-shared.mjs — MapLibre loads its worker from separate files next to the bundle
  • Your config files, wherever you like — a static folder or a CMS field
ESM only MapLibre v6 dropped its UMD build, so the script tag needs type="module". That is fine in every browser map0 targets, but a copied snippet without it silently does nothing.

Talking to it from the page

The element exposes an imperative handle once it is ready, and emits DOM events the host page can listen to without importing anything: 

          const viewer = document.querySelector('map0-viewer');

          viewer.addEventListener('map0:ready', () => {
            const api = viewer.api;
            api.setLayerVisibility('zoning', false);
            api.zoomToLayer('districts');
          });

          viewer.addEventListener('map0:error', (event) => console.warn(event.detail));
